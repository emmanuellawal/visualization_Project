# Cohort: turning a dashboard prototype into an intentional product

## Portfolio summary

Cohort is an interactive workforce explorer that makes comparisons across generation labels easy to inspect. I designed a quiet visual system, implemented custom responsive SVG charts, and made the same data available through keyboard controls, accessible tables, and filtered CSV exports.

## The challenge

The original prototype used an aging React/Vite stack, a large UI and chart dependency chain, and decorative dashboard styling. Its in-app test panel reported hard-coded successes. More significantly, it attributed archived CSVs to official sources without traceable records and contained inconsistent generation age ranges.

## What changed

- Created an editorial identity around a warm paper background, forest-green typography, and four consistent series colors.
- Made the exploration flow explicit: choose generations and years, select a measure, inspect a year, then examine the industry snapshot and source notes.
- Built responsive SVG geometry with numeric year spacing, missing values, distinct dash patterns, keyboard-accessible value inspection, and a semantic table alternative.
- Added URL-persisted filters, sharing with clipboard fallback, filtered exports, and recoverable data-loading errors.
- Replaced weak numeric coercion with typed parsing and validation; added real tests and CI.
- Surfaced data provenance limitations in the interface and exports rather than claiming unsupported findings.

## Skills demonstrated

Product design, React, TypeScript, data modeling, SVG, responsive CSS, accessibility, state serialization, error handling, automated testing, and technical communication.

## What to show

Use the desktop and mobile screenshots generated by the browser suite. A short walkthrough can show generation filtering, the earnings inflation toggle, the matching table, and the share/export actions. Discuss how data integrity influenced both the code and the product language.

## Honest scope

This is a finished portfolio demonstration over archived, unverified data. A research-grade release would require a new, traceable data pipeline and validated cohort definitions. Do not present this case study as evidence of current economic conditions, independently verified statistics, or measured business impact.
